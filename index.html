Understanding Array Indexing

Arrays let a program store many related values under one name. Let's look at a list of temperature readings and learn how Arduino keeps track of each one.

int temperatures[5] = {28, 29, 30, 31, 29};

This line creates an array called temperatures that holds 5 whole numbers. Each value in the array has a position, called an index. In Arduino (and most programming languages), indexing starts at 0 — not 1. So the first temperature is at index 0, the second at index 1, and so on, up to index 4 for the fifth and last value.
